# ตั้งค่า Leaderboard ออนไลน์ด้วย Google Sheets (ทีละขั้น สำหรับคนไม่เคยทำ)

ใช้เวลาประมาณ 10 นาที ต้องมีบัญชี Google (Gmail) 1 บัญชี ไม่ต้องเขียนโค้ดเอง

## ขั้นที่ 1: สร้าง Google Sheets
1. เปิด https://sheets.google.com แล้วกด **"+ ว่าง"** (Blank) เพื่อสร้างสเปรดชีตใหม่
2. ตั้งชื่อไฟล์ (มุมซ้ายบน) เช่น `MitoMon คะแนน ม.4`

## ขั้นที่ 2: วางโค้ด Apps Script
1. ในสเปรดชีต กดเมนู **ส่วนขยาย (Extensions) > Apps Script**
2. จะเปิดแท็บใหม่ที่มีไฟล์ `Code.gs` ลบโค้ดเดิมในไฟล์ออกให้หมด
3. เปิดไฟล์ `tools/leaderboard_apps_script.gs` ในโปรเจกต์นี้ คัดลอกทั้งหมด แล้ววางลงใน `Code.gs`
4. (ไม่บังคับ แต่แนะนำ) ตั้งรหัสห้องเรียนที่บรรทัด `var CLASS_KEY = '';` เช่น `var CLASS_KEY = 'bio4-2569';`
5. กดไอคอน **บันทึก** (รูปแผ่นดิสก์) หรือ Ctrl+S

## ขั้นที่ 3: เผยแพร่เป็น Web App
1. กดปุ่มสีน้ำเงิน **ทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. กดรูปเฟือง ⚙ ข้าง "เลือกประเภท" แล้วเลือก **เว็บแอป (Web app)**
3. ตั้งค่าดังนี้
   - **คำอธิบาย**: `MitoMon leaderboard`
   - **ดำเนินการในฐานะ (Execute as)**: **ฉัน (Me)**
   - **ผู้มีสิทธิ์เข้าถึง (Who has access)**: **ทุกคน (Anyone)**  ← สำคัญมาก ถ้าเลือกอย่างอื่นเกมจะส่งคะแนนไม่ได้
4. กด **ทำให้ใช้งานได้ (Deploy)**
5. ครั้งแรก Google จะขอสิทธิ์: กด **ให้สิทธิ์เข้าถึง** > เลือกบัญชีของคุณ > ถ้าขึ้น "Google ยังไม่ได้ยืนยันแอปนี้" ให้กด **ขั้นสูง (Advanced)** > **ไปที่ ... (ไม่ปลอดภัย)** > **อนุญาต (Allow)**
   (นี่คือสคริปต์ที่คุณสร้างเอง จึงปลอดภัย)
6. คัดลอก **URL ของเว็บแอป** ที่ลงท้ายด้วย `/exec`

## ขั้นที่ 4: ทดสอบ URL
วาง URL ลงในแถบที่อยู่ของเบราว์เซอร์แล้วกด Enter ควรเห็นข้อความ
`{"ok":true,"message":"MitoMon leaderboard is running"}`

## ขั้นที่ 5: ใส่ URL ในเกม
เปิดไฟล์ `js/config.js` หา `LEADERBOARD` แล้วแก้เป็น
```js
LEADERBOARD: {
  ENABLED: true,
  URL: 'https://script.google.com/macros/s/xxxxxxxx/exec',  // URL จากขั้นที่ 3
  CLASS_KEY: 'bio4-2569',   // ต้องตรงกับ CLASS_KEY ในขั้นที่ 2 (ถ้าไม่ได้ตั้ง ให้ปล่อย '')
  TIMEOUT_MS: 8000,
  TOP_N: 10,
},
```
บันทึกไฟล์ แล้วอัปโหลดขึ้น GitHub Pages ตามปกติ

## ขั้นที่ 6: ตรวจว่าใช้งานได้
1. เล่นเกมจนเลเวลอัป 1 ครั้ง (หรือกด Shift+L ถ้าเปิดโหมดทดสอบ)
2. กลับไปดู Google Sheets จะมีชีตชื่อ **Leaderboard** และมีแถวข้อมูลของผู้เล่น
3. ในเกมกดปุ่ม **อันดับ (T)** จะเห็นตาราง 10 อันดับแรกของห้อง

## คำถามที่พบบ่อย
- **แก้โค้ด Apps Script แล้วไม่มีผล**: ต้องกด Deploy > **จัดการการทำให้ใช้งานได้ (Manage deployments)** > ดินสอ ✏ > เวอร์ชัน: **เวอร์ชันใหม่** > Deploy (URL เดิมใช้ต่อได้)
- **เกมขึ้นว่า "เชื่อมต่อตารางอันดับไม่ได้"**: ตรวจว่า URL ลงท้าย `/exec`, ตั้ง "ผู้มีสิทธิ์เข้าถึง" เป็น "ทุกคน" และ CLASS_KEY ตรงกันทั้งสองฝั่ง
- **ถ้าอินเทอร์เน็ตหลุด**: เกมยังเล่นต่อได้ตามปกติ คะแนนในเครื่องไม่หาย (ส่งใหม่เมื่อเลเวลอัปครั้งถัดไป)
- **ข้อมูลส่วนตัว**: ส่งเฉพาะ ชื่อ เลขที่ ห้อง เลเวล อัตราตอบถูก จำนวนข้อ เวลาเล่น และจำนวนเหรียญ
- **เริ่มเทอมใหม่**: ลบแถวในชีต Leaderboard (เก็บแถวหัวตารางไว้) หรือสร้างสเปรดชีตใหม่
